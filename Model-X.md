# Model X Usage Guide / 模型X号使用说明

---

## How to Use

1. Right-click the Blackhole Widget icon in the system tray
2. Click **Model X** in the "Switch Model" submenu
3. Select a `.glb` file in the file dialog
4. The model will auto-scale to fit the window and play its built-in animations

### Interaction

- **Left-drag window** — Move the widget.
- **Right-drag model** — Rotate the 3D model. After release, Model X auto-rotates at the release speed in the drag direction. Right-drag again to set a new rotation speed and direction.
- **Drop files onto window** — Delete files (original feature, unrelated to Model X).

### Notes

- Model X is not persisted — you must re-select a GLB file after each app restart.
- GLB files are provided locally by the user; the app does not modify or upload the original files.
- Only `.glb` (GLB Binary) format is supported; `.gltf` (GLTF JSON) is not supported.
- Built-in animations (rotation, skeletal animation, etc.) are automatically detected and played.

---

## 使用方法

1. 右键点击系统托盘中的 Blackhole Widget 图标
2. 在「切换模型」子菜单中点击 **模型X号**
3. 在弹出的文件选择对话框中，选择一个 `.glb` 文件
4. 加载成功后，模型将自动缩放适配窗口并播放内建动画

### 交互操作

- **左键拖拽窗口** — 移动挂件位置。
- **右键拖拽模型** — 旋转 3D 模型。松开右键后，模型X号会以释放时的速度持续自转，方向与拖拽方向一致。再次右键拖拽可重新设定旋转方向和速度。
- **拖放文件到窗口** — 删除文件（原有功能，与模型X号无关）。

### 注意事项

- 模型X号不支持持久化 — 每次重启应用后需重新选择 GLB 文件。
- GLB 文件由用户本地提供，应用不会修改或上传原始文件。
- 仅支持 `.glb`（GLB Binary）格式，不支持 `.gltf`（GLTF JSON）格式。
- 模型的内建动画（如旋转、骨骼动画等）会被自动识别并播放。
